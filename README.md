# Warm-Up JavaScript

Ce dépôt contient une série d'exercices JavaScript réalisés pendant le warm-up afin de pratiquer les bases du langage et la résolution de problèmes.

## Prérequis

* Node.js installé sur la machine.

## Utilisation

Pour exécuter un exercice :

```bash
node exercice-01.js
```

Remplacez `exercice-01.js` par le fichier que vous souhaitez tester.

## Organisation

Les exercices sont nommés de manière progressive :

* `exercice-01.js`
* `exercice-02.js`
* ...
* `exercice-10.js`

Chaque fichier correspond à un exercice indépendant.
